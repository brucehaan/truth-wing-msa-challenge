### RULE-012 - 마감된 날의 정산서는 이후 어떤 사건에도 바뀌지 않는다

- 기준 시점 : 전표의 businessDate
- 반례 : 1/15 마감 후 1/15 거래가 늦게 도착해 1/15에 적재되면, 이미 발행한 정산서와 원장 합계가 달라진다
- 판정 : 마감된 날짜의 SELLER_PAYABLE 합계가 마감 전후로 같다
- 결정 근거 : 원 전표를 고치지 않고 가장 가까운 열린 날로 이월한다
  - 대안
    - 마감 취소 -> 재마감
    - 기각 - 지급 후에는 불가
- 테스트 : IntakeServiceTest#마감후_도착분은_오늘로_이월된다
